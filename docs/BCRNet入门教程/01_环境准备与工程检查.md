# 01 环境准备与工程检查

## 1. 你要准备什么

当前项目位于 `F:\antiuav\TSCRNet\BCRNet-main`，已存在 Conda 环境 `bcrnet`。本机环境 Python 路径为 `D:\anaconda3\envs\bcrnet\python.exe`。以下命令全部使用 PowerShell 7，也就是 `pwsh.exe`。

先启动 PowerShell 7，再进入项目：

```powershell
Set-Location 'F:\antiuav\TSCRNet\BCRNet-main'
conda activate bcrnet
```

如果 `conda activate` 不可用，后续命令中的 `python` 可以替换为：

```powershell
& 'D:\anaconda3\envs\bcrnet\python.exe'
```

例如：

```powershell
& 'D:\anaconda3\envs\bcrnet\python.exe' -m bcrnet --help
```

## 2. 检查 Python、PyTorch 和显卡

```powershell
python --version
python -c "import torch; print('torch=', torch.__version__); print('cuda=', torch.cuda.is_available()); print('gpu=', torch.cuda.get_device_name() if torch.cuda.is_available() else 'CPU')"
python -m pip check
```

正常情况下：Python 是 3.11；`torch.cuda.is_available()` 为 True；能够打印 NVIDIA 显卡名称；`pip check` 不报告依赖冲突。CUDA 为 False 时仍能在 CPU 上做接口测试，但不适合正式训练。

`nvidia-smi` 显示的 CUDA 版本是驱动支持上限，PyTorch 版本中的 `+cu128` 是 wheel 自带运行库版本，两者不是同一个字段。

## 3. 在新机器上重建环境

```powershell
Set-Location 'F:\antiuav\TSCRNet\BCRNet-main'
conda env create -f environment.yml
conda activate bcrnet
python -m pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -e '.[data,dev]'
python -m pip check
```

其中：

- `environment.yml` 建立名为 bcrnet 的 Python 3.11 环境；
- PyTorch 命令安装当前项目验证过的 CUDA 12.8 wheel；
- `-e` 表示可编辑安装，修改 `src/bcrnet` 后不需要重复打包；
- `data` 安装 OpenCV 与 COCO 评估依赖，`dev` 安装测试和格式检查工具。

如果新机器的驱动或平台不支持该 wheel，应从 PyTorch 官方安装页选择匹配版本，不能机械照抄 CUDA 版本。

## 4. 检查项目入口

```powershell
python -m bcrnet --help
python scripts/extract_antiuav.py --help
```

第一个命令应显示 `train`、`evaluate`、`predict`、`benchmark`。第二个命令应显示抽帧和导出参数。这两个帮助命令不会训练模型，也不会写数据。

## 5. 先跑合成工程测试

```powershell
python -m pytest -q --basetemp=.pytest-bcrnet-local
python -m ruff check src scripts tests
python -m ruff format --check src scripts tests
python -m compileall -q src scripts tests
```

`--basetemp` 必须指向专门的测试临时目录；pytest 可能清理它，所以不能填写项目根目录、数据目录或实验输出目录。

测试通过只能说明接口和已覆盖逻辑没有回归，不能说明模型已在 Anti-UAV 上具备检测精度。

## 6. 推荐的目录习惯

```text
BCRNet-main/
  configs/                 模型、训练和抽帧配置
  data/                    抽帧后的数据，不放原始视频
  docs/                    教程与设计文档
  runs/                    每次训练、评估和预测的产物
  scripts/                 数据准备与检查脚本
  src/bcrnet/              模型代码
  tests/                   工程测试
```

原始 Anti-UAV 数据保留在 `F:\antiuav\main_workspace\Anti-UAV-RGBT`，抽帧输出放到新的 `BCRNet-main\data\...` 目录。脚本会拒绝让输出目录与原始数据目录互为父子，避免误写原始数据。

## 7. 进入下一步前的检查单

- 能运行 `python -m bcrnet --help`；
- PyTorch 能识别 GPU，或你明确只做 CPU 冒烟；
- 项目测试通过；
- 原始数据目录包含 train、val、test、label_new；
- 理解 `runs` 是实验输出，`data` 是抽帧数据，两者不能混用。
